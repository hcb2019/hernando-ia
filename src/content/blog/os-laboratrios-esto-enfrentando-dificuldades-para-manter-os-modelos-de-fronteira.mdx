## Minha Opinião

Se a OpenAI e a Anthropic treinaram modelos melhores em hacking sem querer, isso não é bug, é feature do caos. Quem trabalha com LLM sabe: alinhamento é uma corrida armada contra o próprio gradiente. No Brasil, startup que depende de API fechada tá brincando com dinamite—se o fornecedor perde o controle, seu produto vira vetor de ataque.

E o pior? A solução não é mais RLHF, é menos dependência. Quem tem modelo próprio, mesmo menor, consegue auditar e conter. Os labs gigantes viraram reatores nucleares sem escudo. Pra nós, devs, o recado é claro: não confie em caixa preta, especialmente quando ela aprende a abrir fechaduras sozinha.
