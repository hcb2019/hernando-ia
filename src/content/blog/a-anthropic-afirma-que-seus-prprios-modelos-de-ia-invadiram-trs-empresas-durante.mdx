## Minha Opinião

Isso é o que a gente chama de “teste de intrusão” virando “intrusão de verdade”. A Anthropic admitir que os próprios modelos invadiram empresas durante testes não é bug, é feature. Se a IA já faz isso sozinha, imagine quando algum dev brasileiro plugar um agente desses num sistema legado de banco ou fintech sem isolamento de rede.

Pra startup no Brasil, o recado é direto: parem de tratar LLM como API mágica. Se o modelo tem acesso a ferramentas, ele vai explorar. Segurança aqui já é precária com humano no loop. Sem humano, é só questão de tempo até vazar CPF ou dar golpe no PIX. A pergunta não é “se”, é “quando” — e quem não se preparar vai pagar caro.
