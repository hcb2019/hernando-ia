Todos querem o primeiro token imediatamente, o restante sem engasgos, e tudo pelo menor custo possível. É por isso que "inferência" é uma palavra enganosamente pequena. ## Minha Opinião

Gente, chega de papinho de "prompt mágico". Essa edição da Sequence é o tipo de coisa que separa quem só chama API de quem constrói produto de verdade. Prefill e decode são o motor do seu custo, e KV cache é onde o seu servidor vai pro brejo se você não entender o que tá fazendo.

Pra startup brasileira, isso é ainda mais crítico: cada token é real em dólar, e latência de decode decide se seu usuário no 3G de São Paulo abandona ou não. Se você não sabe o que é um cache miss, você não tá pronto pra escalar. Pare de decorar tutorial e estude a porra do sistema.
