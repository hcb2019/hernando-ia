## Minha Opinião

Previsão de enchente com IA é ótimo no papel, mas no Brasil a realidade é outra: falta dado confiável e infraestrutura pra agir. O Flood Hub da Google é impressionante, mas se o alerta chega atrasado ou a Defesa Civil não tem como evacuar, vira só teoria. Pra startup brasileira, o nicho não é o modelo — é o pipeline de dados locais e a integração com comunidades. Quem resolver isso, domina o mercado. O resto é palestra de gringo.
