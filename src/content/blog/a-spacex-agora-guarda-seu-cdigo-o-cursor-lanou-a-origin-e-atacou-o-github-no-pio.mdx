O Cursor parou de ser editor. Agora é infraestrutura.

E a estreia foi cirúrgica: a **Origin**, nova plataforma de hosting de código da empresa — que desde 14 de agosto é oficialmente da SpaceX —, caiu no ar no exato dia em que o GitHub teve uma das piores quedas do ano. Erro em **20% do tráfego web e API**, chegando a **50% em downloads de repositório e conteúdo raw**.

Coincidência? Se foi, ninguém acreditou.

## O Que Aconteceu

Segundo o **TechCrunch**, o Cursor lançou a Origin essa semana: repositórios, pull requests, navegação e edição de código — o pacote completo que todo mundo usa no GitHub. Só que com agentes de IA embutidos desde o primeiro dia e sync com repositórios que já existem no GitHub.

É o primeiro produto grande da empresa depois da venda de **US$ 60 bilhões** pra SpaceX, fechada no dia 14 de agosto, segundo o TechStartups.

O timing foi de ouro. A Origin saiu na mesma janela em que o GitHub desabou, como registrou o BigGo Finance. O **The Rundown** resumiu com precisão: a Origin bateu no GitHub no pior dia dele.

## Por Que Importa

Porque o Cursor não quer mais ser o editor que você abre do lado. Quer ser a camada de base: onde você escreve, versiona, revisa e shipa.

Faz todo sentido estratégico. Um dev que usa o Cursor como editor principal já vive dentro da ferramenta. Se o Cursor segura o repositório também, ele fecha o ciclo inteiro. O GitHub vira um intermediário desnecessário.

E tem mais. A queda do GitHub não foi só azar — foi a prova de conceito. A Microsoft deixou o GitHub ficar **complacente**: anos sem competidor sério, e a infraestrutura começou a dar tilt. Aí aparece um player com caixa infinito (SpaceX) e zero medo de queimar dinheiro pra ganhar território.

A OpenAI passou anos falando em virar o "sistema operacional do dev". O Cursor tá executando de verdade.

## Minha Opinião

Na moral, tem uma coisa aqui que ninguém tá falando alto o suficiente.

A **TechTimes** pegou: a Origin saiu **sem publicar termos de retenção de dados, sem divulgar subprocessadores, sem política de uso pra treino e sem ferramenta de migração**. Traduzindo: você, dev pagante, entrega seu código pra um braço da **SpaceX** — que é, antes de tudo, uma empreiteira de defesa com contratos bilionários com o governo americano — sem saber o que eles fazem com ele.

A ironia é linda. A galera que desconfia do GitHub "da Microsoft" porque não confia em Big Tech entregando código pra treino... agora tá empolgada em mandar o mesmo código pra um foguete do Elon Musk com **zero** cláusula publicada.

E o pior: o lançamento foi atrapalhado. O Cursor mandou email dizendo que a Origin vazou antes da hora e **fechou o acesso temporariamente**, segundo o BigGo Finance. Ou seja, nem o lançamento saiu limpo, e os termos de dados continuam no vácuo.

Eu não tô dizendo que a Origin é ruim. Tô dizendo que "não publicamos termos" não é bug de beta — é sinal de alerta. O Cursor quer ser o novo GitHub com velocidade de startup, mas sem as amarras que o GitHub herdou da Microsoft. Velocidade boa. Opacidade, nem tanto.

Vou observar de longe por enquanto. Repo de produção meu não migra sem contrato claro de dados. Mas se você é dev e não tá olhando pra essa movimentação, acorda: a briga pelo seu código acabou de esquentar.

## Takeaways

- **Cursor deixou de ser editor** — agora quer o ciclo completo: escrever, versionar, revisar e shipar dentro da própria plataforma.
- **GitHub entregou o timing de bandeja** — a Origin saiu no dia de uma queda grave (20% web/API, 50% downloads). A Microsoft perdeu o monopólio da confiança.
- **O buraco é nos dados** — a Origin saiu sem termos de retenção, treino ou subprocessadores. Seu código ficaria com a SpaceX, empreiteira de defesa, sem cláusula publicada.
- **Não migre no escuro** — beta + sem política de dados + lançamento atrapalhado = observar, não apostar produção.
